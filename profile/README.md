# Sellrika

A point of sale and an online store in one app, for shops, cafés and restaurants.

Products, stock, orders, customers, discount codes, reports, email marketing, a REST API, an MCP server and extensions.

## Start here

- **Use it:** [sellrika.com](https://sellrika.com) — the hosted version, with a free plan.
- **Host it yourself:** [the self-hosting guide](https://developer.sellrika.com/docs/self-hosting) — Docker, SQLite or PostgreSQL.
- **Read the code:** [sellrika/sellrika](https://github.com/sellrika/sellrika) — source-available, under the PolyForm Shield License 1.0.0.
